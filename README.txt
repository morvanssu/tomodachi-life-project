I DIDN'T CHOOSE YOU. THE GAME DID.

QUICK START
1. Open the tomodachi-interactive folder in VS Code.
2. Open index.html with the Live Server extension (right click > Open with Live Server).
3. Alternatively, double-click index.html to open it in a browser.
4. Modify text and the three research files in script.js.
5. Modify colors, layout and fonts in style.css.

FILES
index.html - basic webpage shell
style.css - all styling and responsive layout
script.js - story screens, choices, research copy, and sound
